# KeelWorks UX Team Training

**Interactive Onboarding | Working Agreements & Expectations**

An interactive onboarding and training experience developed for the KeelWorks Foundation User Experience (UX) Team.

## Overview

The KeelWorks UX Team Training program helps new and existing UX team members understand the team's working agreements, responsibilities, collaboration practices, and expectations.

The training combines narrated presentation slides, interactive knowledge assessments, and completion certification to provide a consistent and accessible onboarding experience.

## Training Objectives

By completing this training, participants will learn to:

- Understand UX team roles, responsibilities, and expectations.
- Follow communication and meeting guidelines.
- Maintain accountability for project assignments and deliverables.
- Apply UX design and research collaboration practices.
- Follow documentation and design-to-development handoff standards.
- Understand professional conduct, portfolio attribution, and project transition expectations.

## Training Features

| Feature | Description |
|---|---|
| Interactive Presentation | 14 branded training slides |
| Voice Narration | Female English narration with playback controls |
| Knowledge Assessment | 8 interactive quiz questions |
| Results Review | Detailed feedback on correct and incorrect answers |
| Retake Assessment | Allows participants to retry the quiz |
| Completion Certificate | Generated after achieving a 100% score |
| Print / Save PDF | Printable completion certificate |
| Manager Notification | Prepares an email notification for the reporting manager |
| Responsive Interface | Supports desktop and compatible mobile browsers |

## Getting Started

1. Open the training HTML file in Chrome or Microsoft Edge.
2. Click **Start Training** to begin the narrated introduction.
3. Navigate through the learning modules.
4. Complete the knowledge assessment.
5. Review your assessment results.
6. Retake the assessment if necessary.
7. Achieve a score of **100%** to receive your completion certificate.
8. Enter your name and print or save the certificate as a PDF.
9. Prepare an email notification to your reporting manager.

No software installation or user account is required for the standalone HTML version.
